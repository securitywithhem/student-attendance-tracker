Plan Sprint $ARGUMENTS. Read `docs/backlog.md` and `docs/jira/SAT-export.csv`. List the stories in
"SAT Sprint $ARGUMENTS" with points, assignee and epic; total the points; state the sprint goal.
Flag any story > 5 points for splitting. Write `docs/scrum/sprint-$ARGUMENTS-planning.md` using only
those sources plus notes the user gives you. Ask the user for the real planning date and attendees.
